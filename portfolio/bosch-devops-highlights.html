Resultados em Produção - DevOps Engineer na Bosch

Contexto

Como DevOps Engineer Jr na Bosch Service Operations (plataforma global de compliance TaxCalendar, 8 regiões) e DevOps Intern na Bosch Digital (AskBosch, bot de IA no Microsoft Teams), atuei em infraestrutura Azure, resposta a incidentes de produção, automação de identidade e otimização de custos cloud. Abaixo estão os resultados mensuráveis desses papéis - os números que recrutadores e sistemas de ATS procuram.

Tecnologias Utilizadas

Azure Bicep Terraform Azure DevOps (YAML) Key Vault App Service Function App Event Grid Application Gateway NSG Microsoft Entra ID Keycloak SCIM 2.0 PowerShell Application Insights Log Analytics
Provisionamento como Código
Reduzi o tempo de provisionamento de infraestrutura em 91,7% (2 horas → 10 minutos) ao codificar o ambiente em templates Bicep com capacidade de rollback.
Resposta a Incidentes
Resolvi 6+ incidentes de produção com RTO abaixo de 15 minutos: um incidente de rede identificando um padrão de IP dinâmico do Netskope SASE e aplicando whitelist via NSG; um incidente de SSL/TLS isolando gaps de SNI e RBAC no Azure Application Gateway; e uma falha distribuída em 4 partes (Backend → Event Grid → Function → Email).
Otimização de Custos
Auditei 3 subscriptions Azure e eliminei aproximadamente US$1.774/ano em desperdício de recursos cloud.
Migração sem Downtime
Migrei um Function App entre regiões Azure com zero downtime, desativando 6 recursos legados no processo.
Identidade & Segurança
Autorei um plano de migração de identidade Keycloak → Microsoft Entra ID cobrindo 43+ papéis (roles) e provisionamento via SCIM 2.0.
CI/CD
Reestruturei uma pipeline Azure DevOps YAML inativa, reduzindo falhas de deployment em 85%.
Automação de Certificados TLS
Desenvolvi um sistema PowerShell de renovação de certificados ACME com janela de manutenção dinâmica para rotação automatizada de TLS dentro de NSGs restritas; publicado como open source.
Automação de Onboarding
Construí uma suíte de automação em PowerShell reduzindo o setup de ambiente de horas para menos de 1 minuto.
