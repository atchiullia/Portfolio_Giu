Infraestrutura Profissional por Centavos

Sobre o Artigo

Artigo publicado na Medium da Bosch Engineering documentando como projetei e implantei uma arquitetura AWS profissional para hospedar um site estático com domínio próprio, SSL e CDN global, mantendo o custo operacional abaixo de US$2/mês. O texto detalha as escolhas técnicas por trás do projeto de publicação deste portfólio (S3 + CloudFront + Terraform + GitHub Actions), mostrando que infraestrutura de nível enterprise não precisa de orçamento enterprise.

Ler no Medium →

Temas Abordados

AWS Amazon S3 CloudFront Route 53 AWS ACM Terraform GitHub Actions Otimização de Custos
O Desafio
Como hospedar um site estático com padrão profissional - domínio próprio, SSL, CDN global e alta disponibilidade - sem os custos típicos de uma infraestrutura enterprise.
A Arquitetura
Amazon S3 como origem de armazenamento, CloudFront como CDN global, Route 53 para DNS e AWS ACM para SSL gratuito, tudo provisionado via Terraform e publicado com CI/CD no GitHub Actions.
O Resultado
Custo operacional abaixo de US$2/mês, com infraestrutura como código totalmente versionada, replicável e alinhada a boas práticas de segurança e DevOps.
Onde Foi Publicado
Publicado na Medium oficial da Bosch Engineering (Bosch Tech Brasil), como parte da divulgação técnica de projetos internos de tecnologia da empresa.
