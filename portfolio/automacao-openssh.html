Automação de Configuração de Chave SSH no Windows

PowershellWindowsOpenSSHGitHubGit
GitHub Repo
Descrição do Projeto

Projeto DevOps que automatiza todo o processo de configuração de chave SSH no Windows utilizando PowerShell. O script cria chaves SSH, configura o OpenSSH, e adiciona as chaves ao agente SSH, simplificando o processo de autenticação segura para repositórios Git e servidores remotos.

Objetivo do Projeto

O objetivo foi agilizar o processo de onboarding de desenvolvedores na Crystal Realms Entertainment, automatizando a configuração de chaves SSH no Windows. Isso reduziu etapas manuais, minimizou erros de configuração e acelerou o acesso aos repositórios do GitHub.

como funciona

Tecnologias Utilizadas
01

Criação do Script

Criei um script de automação em PowerShell para padronizar e acelerar a configuração de chaves SSH no Windows

02

Detecção de Privilégios

Implementei detecção de privilégios de administrador com autoelevação, facilitando a execução do script.

03

Automação

Automatizei a instalação e configuração do OpenSSH Client e do ssh-agent, eliminando etapas manuais

04

Geração de Chaves

Gerei chaves SSH seguras do tipo ed25519 e as adicionei automaticamente ao ssh-agent, reduzindo o tempo de configuração em mais de 80%

05

Cópia de Chaves

Copiei a chave pública para a área de transferência automaticamente, otimizando a integração com o GitHub

06

Resultado

Onboardings mais rápidos e consistentes para múltiplos ambientes de desenvolvimento
