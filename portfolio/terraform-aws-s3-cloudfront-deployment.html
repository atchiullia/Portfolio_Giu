Publicação de Site Estático com Terraform, AWS e GitHub Actions

TerraformAmazon S3CloudFrontAWS ACMRoute 53 + SquarespaceAWS CloudWatchGitHub ActionsCI/CDTrivyGitHub Secrets
DockerHub Repo
Descrição do Projeto

Implementei a publicação de um site estático com domínio personalizado (giullialazaro.com) utilizando AWS, Terraform e GitHub Actions, com foco em automação, segurança e infraestrutura como código. Todo o processo foi automatizado via pipeline CI/CD, garantindo entrega contínua com validação de segurança via Trivy e gerenciamento de segredos via GitHub Secrets.

Objetivo do Projeto

Aplicar práticas DevOps e IaC (Infrastructure as Code) para criar um processo de deploy escalável, seguro e monitorado.

como funciona

Tecnologias Utilizadas
01

IaC

Infraestrutura como Código com Terraform: criação automatizada de S3, CloudFront, Route 53, ACM e monitoramento via CloudWatch.

02

Pipeline CI/CD

Pipeline CI/CD com GitHub Actions: build e deploy automáticos a cada push, com validação de segurança via Trivy e gerenciamento de segredos via GitHub Secrets.

03

Segurança

Scan automatizado com Trivy + gestão de segredos sensíveis com GitHub Secrets para proteger credenciais e dados sensíveis durante o processo de build e deploy.

04

Domínio Personalizado

Domínio personalizado (giullialazaro.com) com gerenciamento via Route 53 e Squarespace. SSL via AWS ACM e mapeamento de DNS com validação de CNAME no Squarespace.

05

Monitoramento

Monitoramento via AWS CloudWatch para garantir a disponibilidade e performance do site, com alertas configurados para eventos críticos.

06

Resultado

Deploy seguro e 100% automatizado de um site estático com infraestrutura replicável, SSL, CDN global e domínio customizado.

07

Aprendizados

Integração prática de DevOps com IaC, segurança e deploy web

Publicação

Documentei essa arquitetura no artigo “Infraestrutura Profissional por Centavos”, publicado na Medium da Bosch Engineering, cobrindo como atingir menos de US$2/mês de custo operacional com S3 + CloudFront.
